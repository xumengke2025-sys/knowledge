# 商业航天与卫星互联网

## 定位

以低轨卫星互联网和商业航天产业链为主，拆解卫星制造、载荷、射频/基带、地面终端、卫星运营、测控与发射相关技术。

**与专精特新/先进产业的适配：** 战略性新兴产业 / 未来空间 / 电子信息 / 高可靠器件。

## 技术树

| 节点ID | 名称 | 说明 |
|---|---|---|
| `satellite-manufacturing` | 卫星制造 | 平台、结构、电源、热控、星载计算 |
| `payload-communication` | 通信载荷 | 相控阵、基带、射频、星间链路 |
| `rf-chips` | 射频与微系统 | 射频收发、T/R组件、抗辐照、电源管理 |
| `ground-terminal` | 地面终端 | 用户终端、网关站、卫星地面站 |
| `satcom-network` | 卫星通信网络 | 低轨星座、天地融合、手机直连卫星 |
| `satellite-operation` | 卫星运营 | 转发器、通信服务、网络运营 |
| `ttc` | 测运控 | 遥测、遥控、数传、测控 |
| `launch` | 商业发射 | 运载火箭、可复用火箭、发射服务 |

## 使用说明

- 先读 `taxonomy.json`，再用 `company-universe.json` 做公司落位；
- 关键判断只引用 `facts.jsonl` 中带 source_id 的事实；
- 专利分析从 `patent-search.md` 开始，但正式地图必须做申请人归一和同族去重；
- `expert-pack.json` 用于 FirmBuddy 行业专家创建/培养；
- `training-set.jsonl` 用于试炼和回归，不包含商机题。


## v0.2 覆盖说明

本版本将上市公司 Universe 从少量样本扩展为“已验证样本 + 候选核验池”。`candidate` 仅用于后续检索补证，不能直接作为 FirmBuddy 确定事实。该行业当前深度低于具身智能样板，后续应按同一标准逐步补齐公司卡与代表性专利。
