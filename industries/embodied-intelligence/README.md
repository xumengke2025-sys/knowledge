# 具身智能与人形机器人（深度样板）

本目录是本仓库的黄金样板行业。目标不是提供“概念股名单”，而是建立可被 FirmBuddy 行业专家使用的科技情报知识图谱。

## 覆盖内容

- 13个一级技术节点 + 多个二级技术节点；
- 40+ 家中国大陆上市公司候选/核验对象；
- verified 与 candidate 分离；
- 法定披露/IR/标准等来源索引；
- 公司事实卡；
- 代表性专利与申请人归一；
- 专家训练和反幻觉试炼题。

## 当前边界

- 不声称 Universe 数学意义穷尽；
- 不声称专利样本是全量；
- 不做证券投资建议；
- 不做商机触发。

## 推荐 FirmBuddy 装备槽

- 核心规范：taxonomy + methodology
- 研究资料：facts + company-universe + company-cards
- 监管规则：政策/标准 sources
- 补充资料：patents representative map
