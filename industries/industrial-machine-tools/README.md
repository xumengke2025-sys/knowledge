# 工业母机与高端数控

## 定位

覆盖高端数控机床、数控系统、伺服、电主轴、丝杠导轨、刀具量仪及工业软件，强调精度、可靠性、精度保持性和国产化验证。

**与专精特新/先进产业的适配：** 重点产业链 / 重大技术装备 / 工业基础 / 专精特新高密度领域。

## 技术树

| 节点ID | 名称 | 说明 |
|---|---|---|
| `cnc-machine` | 高端数控机床 | 五轴、车铣复合、磨削、齿轮加工 |
| `cnc-system` | 数控系统 | 控制器、实时系统、插补、智能数控 |
| `servo` | 伺服与驱动 | 伺服驱动、伺服电机 |
| `spindle` | 主轴与转台 | 电主轴、转台、摆头 |
| `linear-motion` | 功能部件 | 滚珠丝杠、导轨、轴承 |
| `tooling` | 刀具与量仪 | 精密刀具、测量、在线检测 |
| `industrial-software` | 工业软件 | CAM、数字孪生、误差补偿、数据采集 |

## 使用说明

- 先读 `taxonomy.json`，再用 `company-universe.json` 做公司落位；
- 关键判断只引用 `facts.jsonl` 中带 source_id 的事实；
- 专利分析从 `patent-search.md` 开始，但正式地图必须做申请人归一和同族去重；
- `expert-pack.json` 用于 FirmBuddy 行业专家创建/培养；
- `training-set.jsonl` 用于试炼和回归，不包含商机题。
