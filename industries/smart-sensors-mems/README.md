# 高端智能传感器与MEMS

## 定位

围绕MEMS、力/压、惯性、气体、柔性、多模态等传感器，建立“敏感材料—芯片—封装—模组—标定—应用”技术链。

**与专精特新/先进产业的适配：** 工业基础 / 电子元器件 / 未来制造 / 机器人与低空共性底座。

## 技术树

| 节点ID | 名称 | 说明 |
|---|---|---|
| `sensing-material` | 敏感材料 | 敏感膜、柔性材料、压阻/压电材料 |
| `mems-chip` | MEMS芯片 | 结构设计、MEMS工艺、ASIC协同 |
| `packaging` | 封装与测试 | 晶圆级/器件封装、可靠性、标定 |
| `force-pressure` | 力/压力传感 | 压力、应变、六维力、力矩 |
| `inertial` | 惯性传感 | 陀螺、加速度计、IMU |
| `gas` | 气体/化学传感 | 电化学、MOS、NDIR、PID |
| `flexible` | 柔性触觉 | 电子皮肤、柔性压力/应变 |
| `sensor-fusion` | 多模态融合 | 传感融合、边缘计算、AI感知 |

## 使用说明

- 先读 `taxonomy.json`，再用 `company-universe.json` 做公司落位；
- 关键判断只引用 `facts.jsonl` 中带 source_id 的事实；
- 专利分析从 `patent-search.md` 开始，但正式地图必须做申请人归一和同族去重；
- `expert-pack.json` 用于 FirmBuddy 行业专家创建/培养；
- `training-set.jsonl` 用于试炼和回归，不包含商机题。
