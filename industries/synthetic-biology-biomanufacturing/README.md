# 合成生物学与生物制造

## 定位

覆盖DBTL研发闭环、底盘细胞/菌株设计、酶工程、高通量筛选、发酵放大、分离纯化以及生物基材料/化学品产业化。

**与专精特新/先进产业的适配：** 未来产业 / 生物制造 / 绿色制造 / 新材料。

## 技术树

| 节点ID | 名称 | 说明 |
|---|---|---|
| `design` | 设计 | 代谢网络、基因线路、计算生物学、AI设计 |
| `build` | 构建 | 基因编辑、DNA组装、底盘细胞/菌株构建 |
| `test` | 测试 | 高通量筛选、组学、自动化实验 |
| `learn` | 学习 | 数据闭环、机器学习、模型优化 |
| `fermentation` | 发酵与放大 | 发酵工艺、过程控制、工程放大 |
| `separation` | 分离纯化 | 提取、纯化、连续化工艺 |
| `bio-based-chemicals` | 生物基化学品 | 氨基酸、有机酸、二元酸等 |
| `bio-materials` | 生物基材料 | 聚酰胺单体、生物基材料 |

## 使用说明

- 先读 `taxonomy.json`，再用 `company-universe.json` 做公司落位；
- 关键判断只引用 `facts.jsonl` 中带 source_id 的事实；
- 专利分析从 `patent-search.md` 开始，但正式地图必须做申请人归一和同族去重；
- `expert-pack.json` 用于 FirmBuddy 行业专家创建/培养；
- `training-set.jsonl` 用于试炼和回归，不包含商机题。
